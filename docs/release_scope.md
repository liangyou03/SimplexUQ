# Public release scope

This repository is a fresh code snapshot. It contains source code, experiment
configurations, tests, dependency specifications, plotting scripts, and rebuild
notes. It does not contain an imported development history.

Excluded intentionally:

- Raw or derived datasets, face images, text collections, and prediction caches.
- API keys, tokens, raw API responses, local environment settings, and checkpoints.
- Reviewer comments, rebuttal drafts, private experimental logs, manuscript drafts,
  internal agent instructions, and audit evidence archives.
- Cluster submission scripts, account-specific server paths, temporary files,
  virtual environments, generated plots, and binary artifacts.

The code is published under the maintainer's personal account. Dataset permissions
remain task-specific; a public code repository does not relicense source assets.
No new general-purpose code license has been granted by this release.
